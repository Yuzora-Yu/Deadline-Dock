# Windowsアプリ内更新

v0.1.13の設定画面に「更新を確認」を追加。

1. GitHubの `Yuzora-Yu/Deadline-Dock/releases/latest` を利用者の操作で確認。
2. 正式版の数値バージョンを比較。ダウングレードとプレリリースは対象外。
3. `Deadline-Dock_<version>_x64-setup.exe` と `SHA256SUMS.txt` を当リポジトリのHTTPS URLから取得。
4. 公開サイズとSHA-256が一致した場合だけ「アプリを終了して更新」を有効化。
5. 利用者が編集内容を保存したことを確認後、インストーラーを起動しアプリを終了。

ダウンロードしたEXEはアプリキャッシュのupdates配下へ保存。起動直前にもハッシュを再確認する。Google処理中はインストーラー起動を待って再試行する。更新完了は標準の日本語NSISインストーラーで案内する。バックグラウンドで強制更新・強制終了はしない。

配布物は現時点では未署名。ハッシュ確認は取得したリリースとの整合性確認であり、コード署名の代替ではない。GitHubとHTTPSの配布経路を信頼境界とする。移動先ホストもGitHubのアセット配信先に限定する。

リリース時は必ず上記の固定命名で両ファイルを添付し、アップロード完了後に正式公開する。v0.1.12以前からは一度だけ新インストーラーで更新する必要がある。

公開APIの読み取りのみの検証:

```powershell
cargo test --manifest-path src-tauri/Cargo.toml live_release_check -- --ignored
```
